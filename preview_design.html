ระยะห่างปลอดภัยช่องจอด (Buffer Time Gap)

ตั้งค่าระยะเวลาปลอดภัยระหว่างรถคันก่อนหน้าที่ออก กับ รถคันใหม่ที่จะเข้าในช่องเดียวกัน:

ระดับผู้ใช้งาน (User Role) หน้าและสิทธิ์การเข้าถึง (Page & Functions Permissions) ผู้ใช้งานตัวอย่าง
System Admin All Pages Page Permissions Functions Permissions Developer / ผู้ดูแลระบบสูงสุด
Admin Booking (คีย์จอง) รถเข้า-รถออก สรุปรายรับ รายงานการจอง ตารางการจอง คุณวิทย์ (Admin)
Staff Booking (คีย์จอง) รถเข้า-รถออก สมชาย, วาสนา (Staff)

แผงจัดการสิทธิ์รายบุคคล & รายฟังก์ชัน (System Admin Console)

*System Admin สามารถติ๊กเปิด/ปิด ทั้งระดับหน้า (Pages) และระดับปุ่มคำสั่ง (Functions on Page) ได้อิสระ
1. สิทธิ์การเข้าถึงหน้า (Pages)
2. ฟังก์ชันการจอง
3. ฟังก์ชันสถานะงาน & ส่งออก
4. ฟังก์ชันตั้งค่าระดับสูง
